# Synthetic Phonics Tutor (HTML)

A browser-based tutor that teaches reading and writing through **systematic synthetic phonics**, step by step.

## Features

- 5 cumulative phonics lessons.
- Sound recall checks.
- Blending practice for reading.
- Segmenting practice for spelling.
- Sentence writing practice.
- Automatic scoring with pass/review result.
- Persistent progress in browser `localStorage`.
- Cumulative review word lists from completed lessons.

## Run

Open `phonics_tutor.html` in any modern browser.

If you prefer serving it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/` (auto-redirects) or `http://localhost:8000/phonics_tutor.html`.
