# Systematic Synthetic Phonics Tutor

A simple command-line program that helps a learner practice reading and writing through systematic synthetic phonics, step by step.

## Run

```bash
python3 phonics_tutor.py
```

## How it works

- Introduces graphemes in a structured sequence.
- Gives blending (reading) checks.
- Gives spelling (writing) checks.
- Repeats a step until the learner reaches a passing score.
